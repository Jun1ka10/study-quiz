## まず知るべきこと

AWS の請求は「使った分」で、上限はありません。設定ミスや放置で膨らみます。守りは 2 つ、**見える化** と **アラート** です。

## 見える化

- **Billing → Cost Explorer**: サービス別・日別・タグ別に集計。まず「先月、何に、いくら」を出す
- **タグ**: `Environment=prod`、`Project=app`、`Owner=xxx` を全リソースに。コスト配分タグとして有効化すると Cost Explorer で分けられる
- **Cost and Usage Report**: 詳細な明細を S3 に。Athena で分析

月初に 5 分、Cost Explorer を見る習慣が一番効きます。

## 予算アラート (Budgets)

- 月額の予算 (例: 100 USD) を作り、50% / 80% / 100% (実績と予測) でメール
- 「予測が予算を超えそう」の通知が、月末の驚きを防ぐ
- 無料枠の利用状況アラートも別にある

## よくある無駄

| 項目 | 何が起きるか | 対処 |
|---|---|---|
| NAT ゲートウェイ | 時間課金 + 転送量。プライベートサブネットからの S3 / 外部 API 通信が全部通る | S3 / DynamoDB はゲートウェイ型 VPC エンドポイント (無料)。不要なら消す |
| 放置した EBS / スナップショット | インスタンスを消しても残る | 「未接続の EBS」を月次で掃除。スナップショットはライフサイクルで世代管理 |
| Elastic IP | 未使用 (どこにも付いていない) と課金 | 使わないなら解放 |
| CloudWatch Logs | 保持無期限、DEBUG を送っている | 保持期間、レベル |
| 止め忘れた開発環境 | 夜も週末も動く | 夜間停止のスケジュール (Instance Scheduler / Lambda)、または使うときだけ |
| 大きすぎるインスタンス | CPU 5% で常時稼働 | Compute Optimizer の推奨を見てサイズダウン |
| データ転送 | リージョン間、インターネットへの送信 | 同一リージョンに寄せる、CloudFront で配信 |

## 常時稼働のものを安くする

- **Savings Plans / リザーブドインスタンス**: 1 年 / 3 年のコミットで 30〜60% 引き。本番の EC2 / RDS のように「確実に動き続ける分」だけ
- **Graviton (arm)**: `t4g` / `db.t4g` は同性能で 2 割安い。Python / PostgreSQL は問題なく動く
- **スポットインスタンス**: 中断されてよいバッチ向け。最大 90% 引き

## 開発環境の考え方

- 本番と別アカウント (Organizations) にすると、請求も権限も分かれる
- 開発の RDS は マルチ AZ 無し、小さいインスタンス、夜間停止 (RDS は最大 7 日停止できる)
- 「試したら消す」を徹底。IaC なら `destroy` で確実に消える

## 月次のチェックリスト

1. Cost Explorer で先月比。増えたサービスは何か
2. 未接続 EBS、未使用 EIP、古いスナップショット
3. CloudWatch Logs の保持期間
4. Budgets の予測が予算内か
5. Trusted Advisor (コスト最適化) の指摘

## まとめ

- 見える化 (Cost Explorer + タグ) と予算アラートが守り
- NAT、放置 EBS、ログ、止め忘れ、が定番の無駄
- 確実に動く分は Savings Plans、arm で 2 割安く
- 月初 5 分のチェックを習慣に

## やってみる

**ゴール:** 予算アラートを作り、今月の内訳と無駄を 1 つ見つける。

1. Billing → Budgets で月額予算 (無料枠のみなら 5 USD) を作り、80% と 100% (予測) でメール通知
2. Cost Explorer で「今月、サービス別」を表示し、上位 3 つを控える
3. EC2 → ボリューム で「使用可能 (未接続)」のフィルタ、Elastic IP で「関連付けなし」を探す
4. CloudWatch → ロググループ で保持期間が「失効しない」のものを探し、30 日にする
5. コスト配分タグに `Environment` を有効化し、今後作るリソースに付けるルールをメモに書く

**確認:** 「今月いくらで、上位 3 つは何」を答えられる。予算アラートが設定された。
